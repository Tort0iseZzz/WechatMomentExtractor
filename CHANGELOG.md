# Changelog

## 1.2.0

首次独立开源发布 / First standalone open-source release.

- Read-only local Moments and comments export to UTF-8 JSON.
- Date, author and text filters; optional reply exclusion and individual selection.
- Large selection dialog with automatically saved choices; responsive main window.
- Filtered or full export, offline backup viewer, and standalone Windows x64 executable.
- Chinese and English usage guides; Apache-2.0 license and upstream attribution.
